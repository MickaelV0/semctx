# Semctx v0.3 delivery checkpoint

## Release scope

The maintainer requested work through publication on 2026-09-13.
[HOK-752](https://linear.app/hoklims/issue/HOK-752) tracks 0.3.0: explicit index recovery,
source-backed continuation, index process lifecycle and voluntary configuration migration.
The [roadmap](../../ROADMAP.md) retains its unmet performance, incremental-indexing, budget and
human-outcome criteria. No provider removal, daemon, executor or automatic migration is included.

## Final candidate and delivery

ADR [0028](../adr/0028-explicit-config-migration-and-restoration.md) defines zero-write planning,
plan-bound application, exact backup and restoration. Only configuration may be replaced;
authored declarations, index data and verification state are preserved. Interrupted operations
retain recovery artifacts. Mutation requires a trusted worktree without concurrent outside writers.

The final candidate combines migration with 0.3.0 metadata and generated artifacts. Targeted,
canonical, aggregate independent and hosted proofs must identify its exact final bytes.
This source document is not a publication receipt. Read the
[release workflow](https://github.com/hoklims/semctx/actions/workflows/release.yml) for verification,
npm publication, registry-ready, stable/GitHub promotion and isolated two-host delivery.

## Preserved limits

Mac/lobby performance and human comprehension, saved time, adoption and retention remain
NOT_MEASURED. Historical thirty-change pilot labels remain UNKNOWN. Synthetic measurements do
not substitute for the private corpus. Full rebuild lifecycle tests do not prove incremental
indexing or power-loss durability. A current index does not validate historical tests or grant
authority. Installation does not activate an open session.

Rollback pins the published 0.2.1; configuration restoration is a separate explicit operation.
Keep original issue criteria, unrelated worktrees and all recorded failed attempts.
