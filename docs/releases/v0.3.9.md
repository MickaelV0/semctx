# v0.3.9: clearer CLI failures and cheaper index-health checks

Semctx 0.3.9 packages the focused maintenance accepted in [PR #206](https://github.com/hoklims/semctx/pull/206).
Ordinary CLI failures report their actual name and message. Plane-A health checks group canonical
scopes, and the MCP server SDK moves to 2.2.0 with the client/core 2.0 baseline retained.

## Install or upgrade

The public registry version and release identity are verified. Install the exact version with:

```bash
bunx semctx@0.3.9 install
```

Runtime/build Bun >=1.4.0 remains the baseline, with TypeScript 5.9.3. Codex CLI 0.147.0 and
Claude Code 2.1.229 are the tested host baseline:
https://github.com/hoklims/semctx/actions/runs/34664142432

Open a new Codex task after installation. In Claude Code, reload plugins and restart if reload
fails. Installation and delivery in fresh profiles do not establish activation in an existing session.

## What changes

- The default CLI error output uses the thrown Error's actual name/message. `SEMCTX_DEBUG=1`
  appends useful frames while discarding a stale stack header. Structured SemctxError handling
  and exit codes stay unchanged.
- Plane-A health checks digest canonical scopes once for grouping, then retain source ordering
  and producer/cardinality checks when selecting results, batches and profiles.
- MCP client/core 2.0 and server 2.2 negotiate both supported protocol eras. The Zod 3 dependency
  and the SDK Zod 4 alias remain in place. No public tool or schema migration is introduced.
- Maintenance pins update ESLint/typescript-eslint, Ruff/zizmor and development types Bun 1.4.2.
  The actual code is checked on Bun 1.4.0; this does not claim every Bun 1.4.2 API works on 1.4.0.
- Regression checks exercise atomic writes with two real processes. The worker benchmark rejects
  an equivalence observed on the wrong parallel, single or named-fallback execution path.

## Measured scope and limits

An instrumentation of the actual `hasExactAnalyzedCardinality` function on 500 scopes reduced
digest calls from 1,000,000 to 1,500. The nominal verdict and three invalid-case refusals were
preserved. This is a bounded function-level observation, not an end-to-end index-health speedup,
a statistical performance estimate or a Lobby benchmark.

The TypeScript extraction memory correction shipped in 0.3.8 is retained. Its matched Windows
probes observed 6–14% lower mono-worker peak RSS with byte-identical facts. See the
[0.3.8 measured scope](v0.3.8.md#measured-scope) for inputs, runtime, options and limitations.
No new memory or speed claim is inferred from the dependency updates.

The proposed parallel canonical scheduler is not enabled. Its gain and resource isolation remain
under [issue #205](https://github.com/hoklims/semctx/issues/205). The existing canonical suite,
ADR 0031 selection and worker smoke remain in place. Oh My Pi support remains experimental;
other host versions and existing-session activation remain UNKNOWN. Adoption, retention and
human contribution time remain NOT_MEASURED.
