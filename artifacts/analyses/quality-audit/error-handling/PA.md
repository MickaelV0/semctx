## Recommendations
1. Treat v1 discovery like v2: unreadable files are `READ_FAILED` candidates, never silent omissions; make `walk` strict by default. Default config is still v1.
2. Stop claiming `analyzed`/`completed` in `buildTypeScriptSidecar` unless extraction covered every TS root with empty parse diagnostics. Empty-graph success must be distinguishable from producer failure so `evaluatePlaneA` can emit `PRODUCER_FAILED` instead of `PASS`.
3. Give `extractTypeScript` the same exact-cover and parse-error accounting the parallel merger / python limitations already have.
4. Cocoindex: `version() === null` remains skip; `search` must not map spawn/nonzero to `[]`.
5. Leave plane-a-internal freshness/binding gates as they are. Do not “fix” STALE/UNSEALED — they already fail closed. Thread `Error.cause` through `SemctxError` and worker failures only.
