# Security — PApp

## Summary
Reviewed App-plane production sources (`packages/app-services`, `apps/cli`, `packages/mcp-server`, `packages/context-engine`, `packages/repository-store`), skipping tests and STRATEGY excludes. SECURITY.md holds on its three core claims: every spawn inspected is an argv array (no `shell: true` / shell string), SQLite values are bound (`?` placeholders; `exec` only of constants), and verify/index/store do no network I/O (optional CocoIndex is adapter-side; plugin attestation is an explicit opt-in `git fetch` to a fixed URL). Worst issue is untrusted-repo path escape: `.semctx` workspace/SQLite writes follow symlinks, unlike the handoff/target-review writers. CLI has no git-style `-C`; `--root` (or cwd) is the only root, while internal `git -C` is used with that root or index gitlink paths.

- Spawn/SQL/path APIs counted: spawnSync/Bun.spawn 12 production sites (plugin-delivery + cli-compatibility have timeout; others do not); SQL `query`/`exec` confined to `packages/repository-store/src/store.ts`; `git -C` 3 sites (`target-review.ts:167`, `verification-state.ts:138`, `verification-state.ts:152`); CLI `-C` is a boolean flag (`apps/cli/src/args.ts:29-30`) and is not a cwd switch (`resolveRoot` uses `--root` or `process.cwd()`)

## Recommendations
1. Apply the control-handoff/target-review symlink containment helper to `initWorkspace` / `openStore` / CLI `.semctx` writers before any other hardening.
2. Make plugin-delivery’s git isolation the default for App git: argv + `--no-filters`/`cat-file blob` + stripped `GIT_*` + timeout/`maxBuffer` (verify/freshness/reconciliation/verification-state/target-review/install).
3. Bound MCP string payloads; keep `SEMCTX_ROOT` process-pin as the documented confused-deputy control when the host would otherwise first-pin an agent-chosen absolute root.
4. Amend SECURITY.md: argv/SQL claims are accurate; “no network in deterministic core” is accurate for verify; mention opt-in plugin attestation `git fetch` and that `.semctx` writers are not yet symlink-safe.
