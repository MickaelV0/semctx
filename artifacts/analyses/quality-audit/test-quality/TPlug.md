# Test Quality — TPlug

## Summary
Reviewed 13 plugin/tooling test files (7746 loc) under `plugins/` (excl. `dist/`), `scripts/test/`, `packages/github-action/test`, `packages/eval/test`, and `packages/test-fixtures/test`. Guard lexer/decision tables, lifecycle ledger verdicts, delivery-proof hostile cases, verify-pr fail-stop, and compatibility substitutions are real contracts. Worst issue is the opposite of coverage: MCP/OMP tests **pin** `cwd: "."` for `bun` and never launch with a consumer `bunfig.toml` `preload`, so the P0 RCE stays green. Next: the blocking PreToolUse guard is only spawned with `JSON.stringify` envelopes (malformed stdin is untested and fail-opens), the Action adapter never sees `STALE`/`{}`/unreadable JSON, and MCP smoke **locks in** UNSEALED → `ok: true` without `canRunHighRiskControl === false`.

## Recommendations
1. Add one behavioral bunfig/preload test for plugin MCP **and** the Action verify step; change parity/OMP from `cwd: "."` equality to “trusted cwd / `--config=/dev/null` + `SEMCTX_ROOT`/`--root` only”. Until then the P0 cannot be fixed without reddening those tests.
2. Copy lifecycle’s raw-stdin case onto the guard with the opposite exit: enabled Bash PreToolUse + garbage JSON → 2, never 0.
3. Untype the adapter fixture. Table `verdict` × `fail-on` including `STALE`, `{}`, schema drift, and unreadable JSON; exit 2 is the closed default.
4. In delivery MCP smoke, archive STALE/UNSEALED only when `canRunHighRiskControl === false`; the live UNSEALED handshake must assert that pairing, not `ok: true` alone.
5. Eval: non-empty golden + empty-suite failure. Delete the two tautologies.
