Verdict/honesty, anchor-migration refusals, target-artifact symlink containment, and link-resolution diagnostics are real contracts (bytes on disk, `STALE` vs underlying `PASS` at `engine.test.ts:151`). Worst issue: `listSemFiles` / `writeAtomic` / `formatSemanticFiles` P0–P1 FS bugs have no test that would catch them.

## Recommendations
1. Add a `store` FS test file first: directory-symlink walk root, planted `.tmp`/dest/`.gitignore` symlinks on every `writeAtomic` publisher, and `formatSemanticFiles(..., true)` with `hasErrors`. That is the P0/P1 coverage hole; path-safety as id-only is not it.
2. Fail-closed tests for observation gaps: `checkSemanticModel({ graphIndexed: false })` must not be `ok`; corrupt `working/active-change.sem` must not equal missing; corrupt `handoff.json` must not equal missing.
3. Keep migration/target/honesty suites. Replace the Worker 5 s `Date.now` poll with a handshake. Delete runtime-vacuous `it`s (type-only L0, `run()===run()`, redundant split length).
4. Leave bunfig `preload` to TPlug (plugin MCP / Action cwd). TB has no launch surface for it.
