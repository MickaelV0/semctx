# Test quality — TC

## Summary
Reviewed Plane C tests only (`packages/control-model/test`, `packages/control-engine/test`, `packages/change-authorization-verifier/test`; 28 `.ts` files, 333 cases). No mocks/`vi.fn`. Capsule forgeries, evidence expiry, and BLOCKED migration plans are well covered. Health is uneven on freshness gates: several suites assert STALE/UNSEALED only when the caller already set `canRunHighRiskControl: false` or when both seals are present and unequal, and some tests treat omitted seals as a successful walk. Worst issue: traversal tests pin fail-open UNSEALED behavior (`lift` without seals → `COORDINATE_UNKNOWN` / `success`), so a fail-closed fix would fail the suite.

## Recommendations
1. Flip TQ-TC-01 first: omitted seals must refuse. Expect the golden/dogfood `lift`/`lower` calls to grow explicit equal seals or to assert `INDEX_STALE`.
2. Add the STALE/UNSEALED × `canRunHighRiskControl` matrix (TQ-TC-02) and the `classifyControlFreshnessSeal` table (TQ-TC-03) in the same change as any production fix for ERR-PC-01.
3. One `ControlQueryEnvelopeV1Schema` case per kind for STALE and UNSEALED (TQ-TC-04).
4. Isolate `INDEX_STALE` and `CONTROL_INPUTS_UNSEALED` in `reconcileDiff`; add non-finite `evaluatedAt` on `authorizeStep`.
5. Keep capsule/replay/report-schema forgeries as the quality bar. Do not add mocks. Do not expand export `toBeDefined` lists.
6. bunfig preload and symlink `.semctx` belong to TApp/TPlug, not this partition.
