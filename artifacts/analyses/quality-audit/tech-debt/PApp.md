# Tech Debt — PApp

## Summary
Reviewed App-plane production `src/` (`app-services`, `apps/cli`, `mcp-server`, `context-engine`, `repository-store`; tests / dist / node_modules skipped). TODO/FIXME/HACK/XXX markers are essentially absent. Shipped lockstep is healthy: `app-services`, `mcp-server`, `semctx` CLI, and both plugin manifests are all `0.1.20` (the STRATEGY “both 0.1.20?” check is a match, not drift). Worst issue is the ADR 0005 retriever still living as a first-class path: `semctx index` still funnels users to `task create`, MCP still registers `semctx_prepare_task` as a writer, and `context-engine` still overlays CocoIndex candidates onto `prepareContextPack`. Secondary debt is frozen version strings (`semctx@0.1.0` pack generator, GitHub Action preset pin `v0.1.18`) and a `@deprecated` `prepareTaskEnvelope` alias that CLI/MCP still call.

## Recommendations
1. Treat ADR 0005 as a cutover, not a footnote: stop advertising `task create` after `index`, drop `semctx_prepare_task` from the default MCP catalogue, and isolate CocoIndex to eval/research.
2. Drive every user-visible version from the CLI lockstep (`0.1.20` today): pack `generator`, `init --preset` Action pin, doctor/compatibility probes. Leave unpublished workspace packages at `0.1.0` if they stay private.
3. Delete the `@deprecated` `prepareTaskEnvelope` alias once `control frame-task` / `semctx_control_frame_task` call `bindTaskScope`. Schedule `migrate anchors` against the same release that retires line-bearing anchors.
4. Do not expand the experimental pack path (new caps, providers, or MCP writers) while it remains demoted.
