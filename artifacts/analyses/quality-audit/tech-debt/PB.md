## Recommendations
1. Close the anchor deprecation for real: tag the identity change, set `LEGACY_SYMBOL_ANCHOR_SHIPPED_IN`, flip `SUPPORT` to `"removed"` in the following release, delete `anchor-migration.ts`. That is the only large “temporary” module in Plane B.
2. Remove the `symbolId(startLine)` overload in the same window. Do not wait for `"removed"` — the overload never writes the deprecated form.
3. Pull ADR 0005 out of `core`: drop `cocoindex` from the config schema; mark `ContextPack`/`TaskFrame` experimental and move retriever-only fields to `context-engine`.
4. Name the 60/40/60 caps. Deduplicate `["critical", "security"]` by reading slice critical tags from `DEFAULT_SEMANTIC_POLICY`.
5. Delete `semantic-engine/src/links.ts` once callers import `semantic-model` directly. Warn-then-drop the `requires` synonym.
