# Code Smells — TApp

## Summary
Inventoried 73 test files (24 127 loc) under `app-services`, `apps/cli`, `mcp-server`, `context-engine`, and `repository-store`. `context-engine` and `repository-store` are healthy (small cases, shared `SAMPLE_REPO` / `EXPECTED`). The rest is fixture soup: 37 local `function git(` copies, 37 `cpSync(SAMPLE_REPO, …)` bootstraps, and seven near-identical `preparedRepository()` helpers across app / CLI / MCP. Health is poor at the transport boundary. Worst issue is two god test files — `plugin-delivery.test.ts` (2117) and `install-cli.test.ts` (1823) — that each ship a Fake Codex/Claude CLI, so host JSON protocol drift is uncaught twice.

## Recommendations
1. Land a test-fixtures `git` + `cloneSampleRepo` first. It pays down SMELL-TAPP-02/03/07/08 in one cut and stops author-identity drift (`semctx-test` vs `Semctx Test` vs `"t"`).
2. Split `plugin-delivery.test.ts` and `install-cli.test.ts` along describes; share one Fake host-CLI. That is the test half of SMELL-PAPP-01.
3. Collapse the seven `preparedRepository` / two `proposalCommand` copies so CLI and MCP cannot diverge on the same sealed fixture.
4. Make `connectMcp` the only way to open an in-memory server; delete the 26 pair pastes.
5. Do not grow `plugin-status-attestation`’s `beforeAll`. Extract the forged world before adding another host.
