## Recommendations
1. Split `prove-stable-delivery.test.ts` first — it is the largest test file in the partition and owns the longest helper (`fakeRuntime`) plus the MCP-handshake paste.
2. Lift `createGuardedRepo` / `runGuard` / `git(repo)` to file scope in `guard.test.ts` and break the 140-loc push-source `it` into unit table vs spawn e2e vs config poison.
3. Give `lifecycle-hook.test.ts` the same `afterEach` temp-dir list as `verify-pr` / `plugin-build`; stop claiming “both hosts” on Claude-only e2e.
4. Split the 125-loc plugin-parity kitchen sink; drop hook-byte and `release.yml` string asserts that `lifecycle-hook` and `governance-files` / `release-workflow` already own.
5. Leave `eval`, `github-action`, `test-fixtures`, `omp-manifest`, `compatibility`, and `plugin-build` alone — they already use small helpers and table-driven cases.
