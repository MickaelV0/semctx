## Recommendations
1. Split `anchor-migration.ts` first. It is the only god file in Plane B and the only one in the 1.5k-loc band.
2. Make `reconciliation-read` a re-export barrel, not a second implementation: one `ChangeContractSchema`, one `.sem` walker, one target loader.
3. Give the `.sem` parser ownership of `link:` spans so migration cannot fork the tokenizer (`locateLinkRefs`).
4. Un-export the dead symbols in SMELL-PB-10/11; do not add new public aliases for private helpers.
5. Leave `format.ts` vs `render.ts` alone — they share a walk shape but one is canonical DSL and the other is a human view; that is not duplication worth collapsing.
