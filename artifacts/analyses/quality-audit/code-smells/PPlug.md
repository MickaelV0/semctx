# Code Smells — PPlug

## Summary
Reviewed plugin hosts (`plugins/claude-code`, `plugins/semctx-control`, `plugins/shared`), `scripts/`, `packages/github-action`, `packages/eval`, and `packages/test-fixtures` (source only; skipped tests, `dist/`, `typescript-lib`). Health is mixed: lifecycle hooks are one shared body copied byte-identically (`sha256 f0a02d00…` on shared/claude/codex), so claude-code vs semctx-control vs shared is **not** a DRY defect. Worst issue is `scripts/prove-stable-delivery.ts` (2551 loc) packing admission, evaluation, live host install, and an MCP client into one module, with `exerciseHost` at 252 loc and `defaultMcpHandshake` at 212 loc. Next is the Claude-only guard (1667 loc) whose shell expander `terminalVerbFromExpandedWord` is 121 loc. Eval/github-action/test-fixtures are small.

## Recommendations
1. Split `prove-stable-delivery.ts` first — it is more than 3× the next script and owns the two longest functions in the partition.
2. Split the Claude guard along lexer / git policy / decision; do not add a fourth fingerprint copy while doing it (ARCH-PPLUG-01).
3. Split `build-plugin-runtime.ts` so bundle bytes and host assets (skills, lifecycle copy) cannot drift in one `main`.
4. Make `runBench` fail closed on an empty case list; delete the duplicated `mean` that turns “no data” into score 1.
5. Trim export surfaces (`scoreCase`, `pluginCliPath`, `bunOnPath`, unused `build-plugin-runtime` exports) to what tests or other packages actually import.
